# Technology inventory

- Rust 2024 and Tokio: server runtime.
- `rmcp`: MCP tool registration and stdio transport.
- `google-cloud-auth`: OAuth user credentials and token retrieval.
- `reqwest`: HTTPS calls to Google and YouTube APIs.
- `serde`, `serde_json`, `schemars`: structured input, responses and MCP schemas.
- `chrono`, `sha2`, `base64`, `getrandom`: time validation and OAuth PKCE.

See [operations](operations.md) for MCP tool inputs and [licenses](licenses.md) for third-party license information.
